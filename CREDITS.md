# Credits

Everything in Pandatize so far was made for this project:

- **logo.png** – my own logo.
- **Home-screen icons** (icons/) – made from logo.png with Windows' own picture tools.
- **Icons** – original line icons drawn in code (js/icons.js).
- **Sounds** – made in code with the browser's built-in Web Audio (js/sounds.js). No sound files.
- **Confetti and animations** – written for this app (js/fx.js, css/motion.css).
- **Code** – plain HTML, CSS and JavaScript written for this app. No outside libraries, fonts, sounds or images.

If anything from outside is ever added, it gets listed here with its name, source and licence.
